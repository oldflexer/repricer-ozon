# План разработки проекта "Репрайсер"

## Этап 1: Разработка архитектуры (День 1)

### Задачи
- Согласовать финальную структуру входной таблицы (колонки: offer_id, название, себестоимость, минимальная цена, ссылки на конкурентов, стратегия, параметры стратегии, временные интервалы).
- Спроектировать схему базы данных SQLite:
  - `products` — текущие настройки товаров
  - `price_history` — история цен и маржинальности
  - `competitor_prices` — история цен конкурентов
- Определить модульную структуру приложения:
  - `config_loader` — чтение таблицы
  - `ozon_parser` — парсинг цен конкурентов
  - `price_calculator` — применение стратегий
  - `margin_calculator` — расчёт маржинальности
  - `ozon_api_client` — работа с Ozon Seller API
  - `max_notifier` — уведомления в MAX
  - `web_app` — веб-интерфейс на Streamlit
- Подготовить шаблон файла `.env` для хранения токенов (Ozon API, MAX Bot).

### Результат
- Краткое описание архитектуры (текстом или в виде списка), отправленное заказчику для подтверждения.

---

## Этап 3: Разработка кода (Дни 2–4)

### День 2
- Реализация `config_loader`: чтение таблицы `.ods`/`.xlsx`, валидация полей, приведение к внутреннему формату.
- Создание модуля `database`: инициализация SQLite, функции записи/чтения истории.
- Реализация `ozon_parser`: асинхронный сбор цен с публичных страниц Ozon по заданным ссылкам (1–5 на товар), обработка ошибок и таймаутов.

### День 3
- Реализация `price_calculator`: логика трёх стратегий (ниже/выше на X%, равная) + поддержка временных интервалов.
- Реализация `margin_calculator`: расчёт текущей маржи, средняя за неделю/месяц на основе истории из БД.
- Интеграция с `ozon_api_client`: отправка цен через `/v1/product/import/prices`, обработка ответов API.

### День 4
- Реализация `max_notifier`: отправка сообщений о завершении цикла и критических ошибках.
- Сборка основного скрипта, объединяющего все модули в единый пайплайн.
- Настройка логирования.

### Результат
- Готовый консольный репрайсер, способный выполнять полный цикл обработки при ручном запуске.

## Этап 4: Проверка (День 5, первая половина)

### Задачи
- Запуск скрипта на тестовых данных заказчика (небольшая таблица с 2–3 товарами).
- Проверка корректности:
  - Чтения таблицы.
  - Парсинга цен конкурентов.
  - Расчёта целевых цен и маржинальности.
  - Сохранения истории в SQLite.
  - Отправки цен в Ozon (тестовый прогон).
  - Получения уведомлений в MAX.
- Отладка краевых случаев (отсутствие цены конкурента, невалидная ссылка, сетевая ошибка).

### Результат
- Стабильно работающий консольный скрипт, подтверждённый тестовым запуском.

## Этап 5: Интеграция на сервер (День 5, вторая половина + День 6)

### День 5 (продолжение)
- Разработка веб-интерфейса на Streamlit:
  - Страница с таблицей товаров (данные из SQLite).
  - Отображение цен конкурентов, текущей цены, маржинальности.
  - Кнопка «Запустить сейчас» для ручного внеочередного запуска скрипта.
  - Базовая аутентификация (логин/пароль).

### День 6
- Аренда VPS заказчиком (Ubuntu 22.04, 1 ГБ RAM, 1 ядро).
- Деплой на сервер:
  - Установка Python, необходимых библиотек.
  - Клонирование кода, настройка `.env`.
  - Настройка cron для автоматического запуска консольного скрипта (например, каждый час).
  - Настройка systemd для автозапуска веб-интерфейса.

### Результат
- Система полностью развёрнута на VPS заказчика, веб-интерфейс доступен по IP.
