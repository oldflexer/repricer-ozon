# Репрайсер для Ozon

Автоматическое управление ценами на Ozon с мониторингом конкурентов, гибкими стратегиями и расчётом маржинальности.

## 🚀 Возможности

- Парсинг цен до 5 конкурентов на товар.
- Стратегии: ниже/выше конкурента на X%, равная цена, временные интервалы.
- Расчёт маржинальности (текущая, средняя за неделю/месяц).
- Обновление цен через Ozon Seller API.
- Уведомления в мессенджер MAX.
- Веб-интерфейс для мониторинга и ручного запуска.
- История в SQLite.

## ⚙️ Входные данные

Excel-файл `products.xlsx` с колонками:

| Колонка | Описание |
|---------|----------|
| SKU | Артикул товара |
| Название | Наименование |
| Себестоимость | Закупочная цена |
| Минимальная цена | Мин. допустимая цена |
| Ваша цена | Текущая цена на Ozon |
| Конкурент 1..5 | Ссылки на товары конкурентов |
| Стратегия | 1 (ниже), 2 (выше), 3 (равная), 4 (расписание) |
| Процент | X% для стратегий 1 и 2 |
| Расписание | JSON с интервалами (для стратегии 4) |

## 🔄 Принцип работы

1. Загрузка данных из Excel → синхронизация с БД.
2. Парсинг цен конкурентов (nodriver).
3. Расчёт целевой цены и маржинальности.
4. Отправка цен в Ozon API.
5. Сохранение истории и уведомление в MAX.

## 📊 Веб-интерфейс

Streamlit-дашборд с таблицей товаров, текущими ценами, маржой и кнопкой ручного запуска.

## 🔔 Уведомления в MAX

Бот сообщает о завершении цикла, количестве обновлённых товаров и критических ошибках.

## 🔧 Требования

- Python 3.10+
- Google Chrome (для парсинга)
- Ozon Seller API (Client ID, API Key)
- MAX Bot Token (опционально)
